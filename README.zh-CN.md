# mtab

[English](README.md) | [简体中文](README.zh-CN.md)

一款适用于 Chrome 和 Microsoft Edge 的可自定义新标签页扩展。

## 安装

### 1. 下载并解压 mtab

1. 打开 [最新版本发布页面](https://github.com/zenaurora/mtab/releases/latest)。
2. 在 **Assets**（资源）列表中下载 `mtab-extension.zip`。
3. 将下载的压缩包解压到电脑上的一个固定文件夹中。

> 安装后请保留解压出来的文件夹。加载扩展时，请选择解压后的文件夹，不要选择 ZIP 压缩包。

### 2. 在 Google Chrome 中安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 并按回车键。
2. 打开右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择解压后的 mtab 文件夹，也就是包含 `manifest.json` 文件的文件夹。
5. 打开一个新标签页，mtab 即可使用。

### 3. 在 Microsoft Edge 中安装

1. 打开 Edge，在地址栏输入 `edge://extensions` 并按回车键。
2. 打开左侧栏中的 **开发人员模式**。
3. 点击 **加载解压缩的扩展**。
4. 选择解压后的 mtab 文件夹，也就是包含 `manifest.json` 文件的文件夹。
5. 打开一个新标签页，mtab 即可使用。
