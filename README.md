# mtab

[English](README.md) | [简体中文](README.zh-CN.md)

A customizable new tab page for Chrome and Microsoft Edge.

## Install

### 1. Download and extract mtab

1. Open the [latest release](https://github.com/zenaurora/mtab/releases/latest).
2. Under **Assets**, download `mtab-extension.zip`.
3. Unzip the downloaded file to a permanent folder on your computer.

> Keep the extracted folder after installation. Do not select the ZIP file when loading the extension.

### 2. Install on Google Chrome

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the extracted mtab folder—the folder that contains `manifest.json`.
5. Open a new tab. mtab is now ready to use.

### 3. Install on Microsoft Edge

1. Open Edge and go to `edge://extensions`.
2. Turn on **Developer mode** in the left sidebar.
3. Click **Load unpacked**.
4. Select the extracted mtab folder—the folder that contains `manifest.json`.
5. Open a new tab. mtab is now ready to use.
